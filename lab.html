怎么读

三步阅读法

① 先看现象：这个改动要消除的具体错误行为是什么？
② 再看根因：是契约理解错了、状态丢失了，还是作用域搞错了？
③ 最后抽象：这条规则换个项目还能用在哪？

怎么加

加入自己的案例

编辑 assets/data/lessons.js，往 cases 里加一条（含 repo / number / theme / problem / root / fix / knowledge / takeaway）， PR 图谱页会自动给它打上「学习卡片」标记；想配动画就在 players 里加一份配置。

所有代码片段均取自对应 PR 的真实 diff（节选），流程类代码会标注为简化示意。
