工程原则

从这些 PR 里抽象出来的六条规则

输入

输入契约要无损

命令解析一旦丢掉「是否被引用」这类信息，下游无法补救。解析层保留语义，入口逻辑收敛成单一函数。

预算

上下文是硬约束

system + 上下文 + 历史 + 输出预留四段记账；换模型要换 tokenizer；历史超预算就从最早的轮次裁。

#2862 #3324
并发

失败是局部事件

gather 默认 fail-fast 会连坐成功结果；用 return_exceptions 分离 Exception 与 BaseException，再按最小粒度重试。

#2829 #3324
取消

取消必须能传播

裸 except 会吞掉 CancelledError；等待别人的地方要有唤醒兜底；取消是终态，要清理用户可见的进度态。

#2832 #2827 #2850
状态

临时改全局要还原

单例配置是全局可变状态：缓存键必须覆盖全部输入维度，临时写入必须 try/finally 配对还原。

#2929 #2856 #2857
观测

观测零副作用

tracing / 埋点失败只告警不改变业务结果；BaseException 要透传；异步任务先登记 Task 才能被取消。
